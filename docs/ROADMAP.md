# Product roadmap

## Milestone 1 — Local MVP
- Telemetry ingestion API
- SQLite persistence
- Explainable rolling anomaly detection
- Incident creation and status updates
- Dashboard service inventory and incident queue

## Milestone 2 — Production foundations
- PostgreSQL schema and migrations
- Authentication, organizations, and role-based permissions
- Rate limiting, payload limits, and audit logging
- Unit, integration, and API contract tests
- CI checks and container security scanning

## Milestone 3 — Observability pipeline
- OpenTelemetry ingestion
- Queue-backed asynchronous processing
- Service-level objectives and alert policies
- Metric aggregation and retention controls

## Milestone 4 — AI incident investigation
- Retrieval over approved runbooks and service documentation
- Evidence-linked incident summaries
- Hypothesis ranking with confidence and uncertainty
- Human approval before operational actions

## Milestone 5 — Operations and scale
- Multi-tenant isolation
- Notification integrations
- Deployment manifests and infrastructure automation
- Load, resilience, and recovery testing
